# 데일리 개편 D1 — 지층이 '쌓이는' 모션 (2026-11-20 10시 개발 교대)

오너 11-18·11-19: 챌린지(데일리) 화면이 "딱딱하고 고전적"이다 → 새 애니메이션·UI·UX.
리디자인 v2 P4·P5·P7로 데일리 화면의 **모양**은 바뀌었지만, /daily 허브(지층 병)와 데일리 시작 화면에는 **움직임이 0**이었다(결과 화면만 모션 있음). 이번 단계는 그 빈 곳을 메운다. 프리뷰 빌드 전용(`@ui-shell` → `src/ui-next/`), prod HTML diff 0.

## 무엇을 바꿨나
1. **지층 병 붓기**: 병이 화면에 들어오면(IntersectionObserver, 40%) 층이 아래부터 위로 부어진다(층당 ≤28ms, 30층이어도 페이드까지 ≤ 900ms). 지시선·캡션·ink 경계는 다 쌓인 뒤 페이드.
2. **오늘 층 '처음' 보는 순간**: 결과 화면의 "+1 stratum" 뒤 /daily로 돌아와 병을 처음 볼 때만, 오늘 층이 병 입구에서 떨어지고(오버슈트 2px) 그 재료색 알갱이 6개가 같은 순간에 바닥에 닿는다. 본 날은 `sandlab.strata.poured.v1 = dayNumber`(기록 키와 별개). reduced-motion이면 그리지도 적지도 않는다.
3. **아직 안 푼 오늘 층**: 점선 윤곽이 3번만 천천히 흐른다('채워질 자리').
4. **데일리 시작 화면**: 제목 묶음 → 보드 → Solve today → 안내가 60ms 간격으로 8px 떠오르고, 실루엣 보드는 어두운 유리에서 '현상'되듯 400ms 동안 밝아진다.

전부 transform·opacity·filter만(CLS 0). reduced-motion이면 즉시 최종 상태.

## 사용자 질문
1. 처음 온 사람: 병이 '붓는다'는 동작으로 "푼 날마다 한 층"이 설명 없이 읽힌다(범례 문장은 그대로).
2. 왜 계속: 오늘 층이 떨어지는 순간이 결과 화면 "+1 stratum"의 실물 — 내일 또 쌓고 싶은 이유.
3. 실패: 영향 없음(플레이 화면 무변경).
4. 어떻게 쓰나: 스크롤해서 병에 닿아야 붓는다(놓치지 않음). reduced-motion·저장 불가(사생활 모드)는 안전한 쪽(그리지 않음 / 한 번 더 붓기).
5. 공유: 이번 범위 밖.
6. 왜 여기서: 기록이 '그래프'가 아니라 손으로 부은 지층 — 경쟁 데일리(Wordle 통계 막대)와 다른 보상.
7. 오너가 볼 때: "병이 작다(112px), 390 오른쪽이 비어 보인다" — 다음 단계 후보(아래).
