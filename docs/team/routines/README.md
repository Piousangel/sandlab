# 루틴 프롬프트 초안 (운영안 v2 — 아직 적용 전)

오너가 루틴 계정에 로그인하고 Slack 커넥터를 연결한 뒤, 메인 세션이 이 초안으로 루틴을 만든다. 그 전에는 루틴을 만들거나 고치지 않는다.
- 파일: `plan.md`(05:37) · `work.md`(01:07·14:07·16:07) · `review.md`(PR ready 이벤트 + 21:37 줍기) · `quality.md`(03:07) · `ops.md`(20:37, 합본 메일 포함). 시각은 [SHIFT](../SHIFT.md) 2장.
- 각 프롬프트 ≤60줄, 필독은 CLAUDE.md·SHIFT·NORTH-STAR·`.claude/handoff/main.md`뿐. 모델·effort는 루틴 설정에서 고른다(문서에 쓰지 않는다): 계획·리뷰는 high, 작업은 medium, 품질·운영·SEO는 low~medium.
- `{작업 팀}` 자리에 시각별 팀 라벨을 넣는다(01:07 = S1 무거움, 14:07 = S2, 16:07 = S2 또는 S1 다듬기). 공통 틀은 허브 `docs/team/routines/`와 같다.
