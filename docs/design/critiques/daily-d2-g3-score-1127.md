## 브리프 요구 위반 (reviewer)
- **A**
  - 연속 점 줄이 병 옆과 병 아래에 두 번 나온다.
  - 병이 보드를 '옆'이 아니라 '덮는다'.
  - 제목·날짜·목표 문장이 통째로 사라졌다. 오늘 퍼즐이 무엇인지 첫 화면에서 빠진다.
- **B**
  - 브리프에 없는 pill 2개와 별 두 줄(★★★ / ●●☆)이 추가됐고, 두 줄이 서로 모순된다.
  - 신규 카드 안에는 글자가 없다(지켰다).
- **C**: 목업이라 pill·점이 없다. '안 푼 날과 순서가 달라지는 혼란'은 정지 화면으로 판정할 수 없다(미재현).

## r2 요청에 넣은 수정 (모두 지금 SVG 병 규칙으로 표현 가능)
1. **오늘 층만 두껍게**: 다른 층의 약 2배(미니 병 안쪽 높이의 약 1/5)로 그린다. 윗변에 흰 알갱이 1줄과 1px 잉크 윤곽을 둔다. 글로우·블러는 금지한다. A의 장점(D1·D2 8)을 B로 옮긴 것이다.
2. **층 색은 재료 팔레트만** 쓴다(`src/lib/sand/materials.ts`): water·sand·lava·acid·stone·plant, 오늘 층은 wood. 보라는 뺀다.
3. **지금 병 문법을 그대로** 쓴다: 살짝 휜 층 경계, 8px 타일 1–2px 사각 점, 흰 세로 반사 막대 1개.
4. **표시는 하나씩만** 둔다: 연속 pill + 7칸 점 1줄, 오늘 별 3점 1줄. 별 두 줄과 남는 pill은 금지한다.
5. **위치 두 갈래**로 뽑는다. 각 1장이다.
   - B2: 카드가 Practice 아래에 있고 화면 높이 3/4 위에서 끝난다. 아래 가장자리에 큰 병 뚜껑이 살짝 보여 '같은 병'으로 이어진다.
   - B3: 보드를 2/3 폭으로 줄여 왼쪽에 두고, 오른쪽에 같은 높이로 미니 병 카드를 둔다. D1을 더 올리는 대조안이다.
- **비용**: flash 2장 ≈₩194, 혹평 1건은 텍스트라 소액이다. **카드 누적은 r1 ≈₩300 + r2 ≈₩200 = 약 ₩500**이다.

## 구현으로 옮길 때 위험 (reviewer, 슬라이스 수락 기준 후보)
1. **두께 규칙 충돌**: 미니 병 층 ≥10px나 오늘 층 2배는 `BASE_H`(7·10·13)와 `buildJar`의 k 압축으로는 나오지 않는다. 미니 병 전용 높이 규칙을 넣으면 큰 병과 미니 병이 같은 날을 다른 두께로 그린다. 그러면 '병이 둘이라 서로 거짓말'하는 것처럼 보이고, 테스트도 두 벌이 된다. 슬라이스는 다음 둘 중 하나를 수락 기준에 못박는다.
   - 미니 병 = 큰 병의 마지막 7일을 같은 비율로 확대(한 모델에서 파생)
   - 브리프 §6 '오늘 층 압축 제외'를 두 병 공통으로 적용
2. **푼 날에만 생기는 블록**: 결과 시트를 닫을 때 카드가 끼어들면 CLS가 생긴다. D1 모션(`isFreshPour`)도 미니 병과 큰 병 중 하나에서만 돌아야 한다(같은 낙하 두 번 금지). 자리를 미리 확보하는 레이아웃이 필요하다(1440은 변화 0).
