# 샌드랩 챌린지(Spill·데일리) UI 전면 개편 방향 (오너 11-18 밤)

> 상태: **방향 확정, 최우선**. 오너 원문: "샌드랩 팀은 챌린지(데일리) UI 자체를 전면 수정해야 할 것 같다. 너무 딱딱하고, 고전(오래된 옛날 느낌)이야." 세부는 팀이 리서치→기획→반증→독립 리뷰(DESIGN-PROCESS)로 정한다. 오너에게 묻지 않는다. 허브와 마찬가지로 "토스·실리콘밸리 기획자" 수준의 주인 의식으로.

## 진단 (11-18 22시, 390px 모바일 라이브 화면 직접 확인: /daily·/play/1-3)
1. **개발 도구처럼 보인다**: 검은 바탕 + 회색 픽셀 벽 + 햄버거·텍스트 진행 막대(`Pot 1 · water 0/100`)·평범한 아이콘 버튼. 색·형태·여백의 체계가 없다. 첫인상이 '게임'이 아니라 '시뮬레이터 데모'.
2. **보상·감정이 없다**: 캐릭터·마스코트 없음, 클리어/실패의 연출 약함, 진행 막대는 무채색 얇은 선, 별(★)은 한 줄 텍스트(`★ Par 2 moves in 5.5s`).
3. **정보 위계가 약하다**: 목표(무엇을 채우나)가 화면 하단 텍스트 목록에 있고 보드 위에서는 점선 상자뿐. 컨트롤(Dig/RUN)은 모서리에 붙고 그 아래는 큰 빈 공간(1,200px 이후). 상단 되감기·재시작·배속 원형 버튼이 보드 위에 떠서 보드를 가린다.
4. **재료가 살아 보이지 않는다**: 모래·물·돌이 단색 노이즈 텍스처. 샌드랩의 매력(모래가 흐르고 물이 차는 쾌감)을 화면이 못 살린다.
5. **월드·진행감이 없다**: 레벨 목록이 텍스트 리스트. 2-1(불) 같은 새 월드의 설렘을 줄 지도·잠금 연출이 없다.

## 방향(팀이 라운드 1에서 반증·구체화)
- **톤**: 따뜻하고 장난감 같은 퍼즐 게임(예: 부드러운 모서리, 채도 있는 팔레트, 재료별 색 체계, 은은한 글로우). '옛날 게임'이 아니라 '지금 앱스토어 상위 퍼즐'의 마감. 레퍼런스 조사 필수(Toss·Duolingo식 마이크로 인터랙션, Cut the Rope·Where's My Water·Powder Toy 등) — 가져올 것/가져오지 않을 것 표.
- **캐릭터/안내자**: 허브의 말랑이처럼 일관된 캐릭터 1개(샌드랩 고유, 모래 정령 등)로 온보딩·실패·클리어에 감정을 준다. Gemini 아트 비용 규칙(docs/team/GEMINI.md, 월 ₩40,000 가이드·재사용 우선) 준수.
- **보드·재료 렌더**: 모래 반짝임·물 표면/반사·벽 질감 등 재료 셰이더급 개선(성능 예산 내, 모바일 60fps 유지).
- **HUD 재설계**: 목표를 보드 위 컴팩트 '목표 칩'(아이콘+진행 링), 별 목표 시각화, 컨트롤 엄지 영역 재배치(하단 중앙), 보드를 가리지 않는 되감기/배속.
- **클리어/실패 연출**: 별 획득 애니메이션, 한 줄 격려, 다음 레벨·데일리·공유 CTA(연결고리 진단 B와 통합), 햅틱·사운드.
- **레벨 선택**: 월드 지도형(진행·잠금·새 월드 예고), 데일리 카드의 존재감.
- **데일리**: 오늘의 퍼즐 카드, 스트릭·전 세계 클리어율 자리(서버 준비는 리더보드 S0~S2와 연계).

## 제약(깨면 안 되는 것)
- 시뮬·솔버·`spill:verify`·결정성은 그대로. UI 변경이 시뮬 결과를 바꾸면 안 된다.
- **광고를 게임 화면에 넣지 않는다**(verify-ads 유지). AdSense 심사 중 큰 라우트 구조 변경 금지는 유지 — 화면 내부 개편은 허용, URL 이동은 금지.
- 모바일 스크롤·터치 규칙(`touch-action`, 보드 밖 스크롤 가능) 유지, 390px 기준 먼저.
- 접근성·소리 끔·`prefers-reduced-motion` 지원.

## 진행 방식(권장, 팀이 바꿔도 됨)
1. 라운드 1(리서치 1 + 기획 v1): 레퍼런스 8종 이상, 현재 화면 문제 목록, 비주얼 시스템 초안(팔레트·타이포·형태·캐릭터), **Gemini 시안 3~4장**(비용 규칙 안에서).
2. 라운드 2(반증+기획 v2) → **독립 리뷰** → 시안 확정. 오너에게 시안 승인을 묻지 않는다(팀 결정), 결과를 보고만 한다.
3. 구현은 **단계 출시**(하루 1개 이상 눈에 보이는 개선): ① HUD·목표 칩·컨트롤 재배치 ② 클리어/실패 연출 ③ 재료 렌더 개선 ④ 레벨 선택 지도 ⑤ 캐릭터 통합. 각 단계 390px 캡처 + 독립 혹평 6.5점 이상에서 출시.
4. 측정: `daily_start`, 레벨 시작→클리어 전환, 재시도율, 공유율(이벤트 계획은 팀이 정함). 신규 월드 도달률.
