## 3. 하지 않을 것
1. **시뮬 품질·엔진·격자(1200×600) 손대기.** 손맛은 UI·입력·모션으로 올린다(CLAUDE.md 절대 규칙).
2. **공유 링크(`#s=`·`#g=`·`/s/:id`)·레벨 id 형식 변경.**
3. **레벨 수 채우기·솔버 미검증 공략, 매일 새 미니게임, 댓글.** 레벨 하나에 "아하" 하나, 주장은 `spill-explore`로 확인한 것만.
4. **게임·캔버스 화면 안 광고, AdSense 재심사 신청, 에이전트의 외부 서비스 직접 호출**(SNS 게시는 대기열 PR → Actions만, [OPS](OPS.md) 5장 — 오너 11-24).
5. **classic 화면 장식 개편, Vercel.** 새 화면은 Glass & Grain에만, 컷오버 때 옛 화면을 지운다.

## 5. 결정 원칙 (오너에게 묻기 전에)
1. **신뢰 > 속도.** 오답을 떨어뜨리는 검사(spill:verify·verify-ads·골든셋·단어 수 비교)가 통과하지 않으면 머지하지 않는다.
2. **되돌릴 수 없는 것만 무겁게.** 공유 링크·레벨 id·D1 쓰기·광고 위치·컷오버는 `고위험`(리뷰 2회), 애매하면 오너에게. 화면 롤백(빌드 변수 1줄)은 가볍게 본다.
3. **북극성에 가까운 일 먼저.** 첫 붓기 → 데일리 시작 → 클리어 → 공유 → 내일 길을 짧게 하는 일 > 유입(SEO·공유) > 새 레벨 > 장식.
4. **깊이 > 개수.** 솔버로 확인되지 않은 레벨·공략은 내지 않는다.
5. **숫자로 판정, 없으면 측정부터.** 14일 창으로 판정한다. n < 30이면 숫자 대신 검사·재현·플레이 테스트 증거로 판정하고 "표본 부족"이라 적는다.
