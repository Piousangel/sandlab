### 0-2. 바꿀 수 없는 것 (기술 고정) vs 전부 자유

**고정 (바꾸면 사고)**
1. **시뮬레이션 엔진**: `src/lib/sand/engine.ts`·`shader.ts`·`params.ts`(WebGPU 홈), Spill CPU 시뮬·솔버·결정성(`spill:verify`), Margolus 불변식. 시뮬 품질·물리 규칙·재료 반응표 불변(CLAUDE.md "시뮬 품질에 더 붓지 마라").
2. **격자 1200×600** 및 재료 ID·순서(`materials.ts` 인덱스) — 공유 데이터가 ID를 담는다.
3. **공유 URL 형식**: `#g=<base64url(deflate(RLE))>` (v=1, `urlState.ts`) — 어느 경로에서 열려도 디코드돼야 함. 갤러리 `/s/:id`(Worker OG 셸) 경로·API(`/api/*`) 그대로.
4. **SEO URL**: `/`, `/play`, `/play/:id`, `/play/:id/guide`, `/daily`, `/gallery`, `/learn`, `/learn/:slug`, `/materials`, `/materials/:slug`, `/about`, `/privacy`, `/terms`, `/contact` (sitemap.ts 기준). 각 페이지의 h1·title·description·JSON-LD·본문 텍스트 분량 유지(AdSense 재반려 방지).
5. 운영 규칙: Cloudflare Workers 정적 export, 게임 화면 광고 금지(verify-ads), 댓글 기능 없음, D1 스키마.

**자유 (전부 새로)**: 앱 셸·내비게이션·레이아웃·색·타이포·아이콘·컴포넌트·팔레트 UX·입력 제스처·HUD·결과 화면·데일리 흐름·레벨 선택·갤러리 UX·재료 페이지 구성·사운드·모션·공유 카드·온보딩·설정. 렌더 '표현층'(보드 위 SVG/Canvas2D 오버레이, Spill 보드의 색 팔레트 매핑)도 시뮬 결과를 바꾸지 않는 한 자유.

3. **제약된 팔레트 + 모노 라벨** (TE) → 장식색 금지, UI 색은 재료에서만 빌린다.

6. **스포일러 없는 자랑** (Wordle·Wrapped) → 결과 카드는 풀이를 숨기고 '성취의 모양'만.

#### 광고 자리의 품위
- **게임 화면(/, /play/*, /daily 보드 영역) 0개** — verify-ads 유지.
- 콘텐츠 페이지(/materials, /learn/*, /about, /gallery 하단)에만, **"전시 안내판"** 형식: Bone보다 한 톤 어두운 판, 위에 `ADVERTISEMENT` 모노 9px 라벨, 고정 비율 박스(높이 예약 → CLS 0), 버튼·링크와 최소 24px(권장 48px) 간격(우발 클릭 정책).
- 본문 3~4섹션마다 1개, 데스크톱은 우측 여백 sticky 1개 이하. 광고 색은 통제 불가하므로 주변을 무채로 둬서 '액자 밖'임을 분명히.

#### 추천 이유
1. **독창성**: 장르 관습을 깨면서도 샌드랩 시뮬의 본질(물질)을 UI로 끌어올린다. 다른 사이트가 복제하려면 같은 엔진이 필요하다(루프가 우리 엔진 캡처).
2. **오너 피드백 직결**: "딱딱·고전" → 유리·모래의 촉감과 연출, "거듭할수록 더 하고 싶게" → 지층·표본 선반·빈 유리알.
3. **브랜드 분열 해결 + 옛날 느낌 원인 전부 제거**: 홈(다크)·Spill(크림)을 버리고 "Bone 크롬 + Kiln 우물" 하나의 앱 셸로 새로 짠다. 0-1의 R1~R12를 '오브젝트 UI'로 구조적으로 제거할 수 있는 유일한 안(A는 R2·R6, B는 독창성에서 남는다). #55의 크림 K 토큰·SVG HUD는 계승 의무 없음 — 새 컴포넌트로 대체.
4. **AdSense·SEO 친화**: 글 페이지는 안 A의 에디토리얼 장점을 흡수(Field notes 섹션). 광고는 액자 밖 안내판.
5. **비용 효율**: 핵심 에셋(재료 루프·결과 프레임)은 **우리 엔진 캡처 + 코드 SVG**라 Gemini 예산을 거의 안 쓴다. 마스코트 없음 → 캐릭터 일관성 리스크 제거(안 B의 약점).
6. 안 B의 '따뜻함'은 둥근 모서리·스프링 모션·재료색 채도로 흡수, 안 A의 '우아함'은 모노 라벨·캡션·여백으로 흡수.

### 3.2 타이포
- **Display/UI**: Bricolage Grotesque (Google Fonts, 가변 wght·opsz, OFL) — 약간 거친 획이 '알갱이' 느낌, 범용 시스템 폰트 탈피. 라틴 서브셋 self-host, 400·700 두 축만, 예상 ≈40KB woff2 [추정].
- **Mono(라벨·계기판·숫자)**: JetBrains Mono 또는 IBM Plex Mono 500 (≈20KB 서브셋) — TE 문법.
- 숫자: `font-variant-numeric: tabular-nums`.
- 스케일(390 기준 / 1440): `display 40/64` · `h1 28/40` · `h2 20/24` · `body 16/17 (lh 1.55)` · `label 11/12 mono, letter-spacing .08em, uppercase` · `gauge 24/32 mono`.
- 성능: `font-display: swap` + `size-adjust`로 폴백 메트릭 맞춤(CLS 방지), Display만 preload. 기존 "웹폰트 없이" 결정(R1 3.1)을 뒤집는 것이므로 **DECISIONS.md에 근거 기록 필요**(LCP 영향 측정 후 확정).

### 3.3 간격·모서리·그림자
- 간격: 4px 베이스 `4 8 12 16 24 32 48 64`. 터치 타깃 ≥44px, 도크 높이 64 + safe-area.
- 모서리: `r-xs 6`(칩) · `r-sm 10`(버튼) · `r-md 16`(카드) · `r-glass 22`(유리 용기·액자 안쪽) · `pill 999`. 시험관은 아래만 둥글게(`0 0 14 14`).
- 그림자(블러 남발 금지 — north-star 감점 요소):
  - `--lift`: `0 2px 0 rgba(42,33,24,.18)` (눌림 가능한 것)
  - `--glass`: `inset 0 1px 0 var(--glass-hi), inset 0 -2px 0 var(--glass-lo), 0 6px 14px -8px rgba(42,33,24,.35)` (용기·액자)
  - `--press`: 눌림 시 translateY(2px) + lift 0.

### 3.6 사운드 톤
- 성격: **건조하고 가까운 실물 소리**(쌀알·모래를 유리병에 굴리는 녹음 질감) + 유리 '틴'. 전자음·8bit 금지(고전 느낌 강화).

- 햅틱: Android `navigator.vibrate(10)` 탭, `[12,40,18]` 액자. iOS Safari 미지원 → 무음 대체 [추정: iOS는 vibrate 미지원].

### 3.7 접근성
- 캔버스 `role="img"` + 동적 `aria-label`(“Sand canvas, 412,000 cells moving”), Spill 목표는 텍스트 대체 유지(render.test.tsx 기존 라벨).
- 색만으로 구분 금지: 재료 = 색+결 패턴+이름, 별 = 채움+체크 형태, 비커 = 눈금 숫자.
- 포커스 링: 2px `--ink` + 2px bone 오프셋, 시험관 랙은 방향키 로빙 탭인덱스.
- 결과 다이얼로그: 포커스 트랩·Esc·`aria-live="polite"`로 "Cleared, 2 of 3 stars".
- 텍스트 대비 4.5:1(본문)·3:1(큰 글자·아이콘), 재료 장식색은 텍스트 금지(현 함정과 동일 규칙).
- 소리 끔·모션 줄임·햅틱 끔 3토글을 한 시트에.

## 5. 실행 계획 — 전면 교체 (PR 12개) + 마이그레이션

### 5-0. 전략: "새 셸을 옆에 짓고, 한 번에 갈아탄다"
- **단계별 덧칠 vs 한 번에 교체 판단**: 덧칠(기존 컴포넌트를 하나씩 교체)은 중간 몇 주 동안 R11(두 디자인 언어)을 **세 개**로 늘리고, 오너가 매일 "아직도 옛날 같다"를 보게 된다. 반대로 빅뱅 무검증 교체는 AdSense 심사·SEO·공유 링크 리스크가 크다.
- **결론: 병행 구축 → 단일 컷오버(하이브리드)**.
  1. 새 앱 셸을 `src/ui-next/`(새 디렉터리)에 **같은 라우트 파일 안에서 플래그로 분기**해 짓는다. 라우트(URL)는 새로 만들지 않는다 → SEO URL·sitemap 불변.
  2. 플래그: `?ui=next` 진입 시 쿠키 `ui=next` 설정, 쿠키 있으면 새 셸 렌더(정적 export이므로 클라이언트 분기 + 서버 HTML은 양쪽 텍스트 동일 유지). 팀·오너·자동 혹평·Playwright만 새 셸로 본다.
  3. 새 셸이 **전 라우트 동등 기능 + 검증 기준**을 통과하면 하루에 기본값을 뒤집는다(컷오버). 옛 셸은 `?ui=classic`으로 2주 보존 후 삭제.
- **기능 동결 기간**: 컷오버 대상 화면에 대한 새 기능(레벨 추가 제외)은 **PR 1 머지일 ~ 컷오버 후 1주(약 3주)** 동안 동결. 데일리 레벨 풀·Spill 레벨 추가·버그 수정·콘텐츠 글 추가는 허용(데이터/콘텐츠는 셸과 무관하게 양쪽에 보임). 하루 1출시 원칙은 "ui-next 단계 출시(플래그 뒤)"로 충족하고, 매일 ui-next 390 캡처를 보고에 첨부.

### 위험과 대응
**성능 (캔버스·모바일 GPU)**
- 홈 WebGPU 컨텍스트 외에 **추가 GPU 컨텍스트를 만들지 않는다**. 팔레트·갤러리 썸네일은 영상/WebP 루프, 갤러리 라이브는 동시에 1개.
- UI 파티클(가짜 알갱이)은 Canvas2D 단일 오버레이, 300개 상한, 결과 연출 동안만. 시뮬 프레임 예산(현 4ms 게이트, /spill/bench)과 별도 측정.
- 유리 효과에 `backdrop-filter` 금지(모바일 GPU 비용) — inset 그림자·1px 하이라이트로만.
- 루프는 IntersectionObserver + `prefers-reduced-data`/저사양(`navigator.hardwareConcurrency ≤4`)에서 포스터만.
- iOS Safari WebGPU 지원 범위는 [추정] 불확실 → 폴백 영상·Spill(CPU) 경로 유지.

**AdSense**
- 심사 중 **라우트 이동 금지** → 전면 교체여도 URL은 그대로, 화면 내부만 새로. 심사 진행 중이면 컷오버를 결과 이후로 미루는 선택지 유지. 게임 화면 광고 0 유지(verify-ads).
- 텍스트 본문을 '접힘'으로 숨기지 않는다(가치 없는 콘텐츠 재반려 위험). Field notes는 기본 펼침.
- 광고 안내판은 인터랙티브 요소와 간격 확보, "Advertisement" 라벨은 허용되는 표기만(“Sponsored” 등 오해 표현 회피) [추정: 정책 문구 재확인 필요].

**SEO**
- h1·title·description·JSON-LD·sitemap 불변. 폰트 교체는 CLS 0 유지가 조건.
- 루프 영상은 `<video muted playsinline loop>` + 포스터 + 텍스트 캡션(이미지 검색·접근성).
- 공유 OG 이미지 경로 추가는 새 URL이 아니라 정적 에셋(`/og/daily-42.png`) — 라우트 변경 아님.

**제품 리스크**
- "예쁜데 느리다" → PR5·9에 성능 게이트 수치 고정.
- 지층이 localStorage라 기기 바꾸면 사라짐 → 리더보드 S1(IP 해시) 연계 시 서버 백업 검토, v1은 "이 브라우저에 저장됨" 명시.
- 폰트 결정 번복(라운드1의 시스템 폰트 원칙) → DECISIONS.md에 측정치와 함께 기록, 롤백 가능하게 변수 1곳.
