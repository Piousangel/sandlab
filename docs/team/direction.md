# 팀 방향 (살아있는 문서)

아침 팀이 매일 갱신한다. 틀린 줄은 지우고, 쌓아두기만 하지 않는다. 작성 규칙은 [OPERATING.md](./OPERATING.md) 4장.

## 현재 방향 (3줄)
1. AdSense 승인: 하루 1개씩 Spill 레벨과 공략(시뮬로 확인한 주장만)을 쌓아 고유 콘텐츠를 늘린다(DECISIONS 11-10).
2. 유입: AE referrer는 전부 sandlab.app이지만 Search Console에 28일 Google 클릭 30회(11-12 메일)가 있다. 마케팅 실제 게시를 11-13부터 시작한다.
3. 첫 화면: 데스크톱 홈은 빈 샌드박스만 보이고 데일리·퍼즐 진입이 첫 화면에 없다. 콘텐츠로 들어가는 길을 만든다.

## 부족한 점 (확인된 것)
- **외부 유입 0**(11-13 회의).
- **측정 공백**: Spill 클리어·갤러리·데일리 D1 지표가 토큰에 D1 권한이 없어 빠져 있다. 어제 출시물의 반응을 측정하지 못한다.
- **QA 공백**: 클라우드 세션에서 sandlab.app curl이 403이다(환경 네트워크 허용 목록).
- **레벨 난이도 편차**: 1-6 클리어율 92% vs 다른 레벨 4~48%.
