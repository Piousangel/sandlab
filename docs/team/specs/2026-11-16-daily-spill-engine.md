# 스펙: /daily를 Spill 엔진으로 교체 (큰 기능 후보 2, 옛 S3)

## 목표와 사용자 가치
데일리 도전이 옛 챌린지 엔진(WebGPU 1200×600 계열)에 남아 있어 엔진이 이중이다. Spill 엔진(CPU, 폰 지원)으로 통합하면 폰·미지원 브라우저 방문자도 매일 돌아올 이유가 생기고, 코드 두 벌 유지 비용이 사라진다.

## 완료 조건
- `/daily`가 Spill 레벨을 UTC 날짜로 결정론적 선택(기존 LAUNCH_UTC 번호 체계 유지)해 플레이. 하루 한 번 클리어 기록(별 수), 기존 `/api/daily` 통계 호환.
- 공유: 결과 문구 + 링크(공유 URL 형식 변경 금지). 순위표 없음(기존 결정).
- 옛 `src/lib/challenge` 데일리 경로 제거는 이 PR이 아니라 후속(롤백 가능성 유지).

## 측정 지표
`daily_start`·`daily_clear`(기존 challenge 이벤트와 별도 이름), 7일 재방문(landing `direct` 비율 변화).

## 하지 않을 것
순위표·계정·댓글, 시뮬 품질 작업, 격자 변경.

## 단계
1. 레벨 풀·날짜 선택기(순수 함수 + 테스트) 2. DailyPlayer를 SpillPlayer 래퍼로 교체 3. 기록·통계 API 호환 4. 옛 경로 정리(후속 PR).
