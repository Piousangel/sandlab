# 레퍼런스: 비주얼/UX 디자인 — 실렌더 크리틱

디자인 크리틱이 실제 렌더 스크린샷을 best-in-class(Sandspiel·Powder Toy·Sandboxels) 대비 평가.
(연구 사이클 visual 페르소나가 3번 스키마 실패 → 단일 크리틱 에이전트 + 실스크린샷으로 대체.)

## 원칙
- 이 장르는 **시각적 만족(oddly-satisfying 클립·썸-스톱 썸네일)으로 퍼진다.** 첫 3초 인상이 곧 제품.
- **AI-슬롭 3대 지문 = 다크 + 파란 액센트 + 유리.** 카테고리를 소유하려면 자기 색을 UI 크롬까지 내린다.
- 이 제품의 색 정체성 = **따뜻한 앰버/샌드**(OG·앰비언트·사구·용암 글로우).

## 처리됨
- **[✅] 살아있는 첫 프레임** (7272746) — 빈 캔버스에 앰비언트 자동 연출(흐르는 발광 스트림). 죽은 검은 박스 해결.
- **[✅] 브랜드 앰버 통일** (622fb2a) — 제네릭 블루 #3b6dff → 앰버 #f5a623(다크 텍스트 #1a1206).
  Record만 시그니처 레드-오렌지 #ff5a2c(용암, '캡처' 차별화). 워드마크 15→18px, 서브카피 0.45→0.6, 스탯 0.34→0.5.
- **[✅] 갤러리 썸네일 onError 폴백** — 그라디언트 플레이스홀더(깨진 카드=고장 신호 방지).
- **[✅] 공유 패널 주액션 하나로** (88458b0) — 모바일 Copy 고스트/Share 주액션.

## 남은 디자인 백로그 (agent-safe, browse 검증 가능)
- **[M] #4 모바일 데드스페이스** — 2:1 캔버스가 세로 폰에서 얇은 밴드, 위아래 큰 검정. 상단 공백에
  워드마크/사구, 하단은 도크로. `S.stage`가 세로에선 콘텐츠를 위로 붙이고 빈 공간을 브랜딩으로.
- **[M] #6 도크 위계** — Publish/Gallery(리텐션 루프)가 고스트로 파묻힘, 파괴 액션 Clear가 Publish와
  같은 무게. Publish를 앰버 아웃라인 2차 강조, Clear를 우측 끝 분리, Copy link는 Publish 성공 후로 흡수 검토.
- **[S] #5 후속** 공유 패널에 방금 만든 씬 2:1 썸네일 프리뷰 추가(자부심·만족 모먼트).
- **[S] #7 색 칩** 선택 링을 액센트+스케일로 더 뚜렷이, 유사 원소 그룹 구분, selName 강조.
